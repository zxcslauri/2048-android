# 2048

A customizable Android implementation of the classic **2048** puzzle game.

The project focuses on giving the player extensive control over the game's appearance while keeping the interface simple and lightweight.

## Features

- Classic 2048 gameplay
- Customizable visual themes
- Individual colors for numbered tiles
- Custom game background
- Adjustable transparency for interface elements
- Customizable interface colors
- Multiple interface languages
- Saved language preference
- Lightweight XML-based Android UI

## Customization

The main goal of the project is to make the appearance of the game highly customizable.

Customization includes:

- Tile colors for every number
- Background color
- Custom background image
- Transparency of the game board
- Transparency of interface elements
- Text and accent colors
- Custom themes

The theme system uses Android color resources, making it possible to change groups of related interface elements without modifying every individual view.

## Languages

The project supports multiple interface languages.

Currently available:

- 🇷🇺 Russian
- 🇬🇧 English

The language system is designed to be easily extended with additional translations.

Each translation can contain:

- Language code
- Language name
- Translator information

## Tech Stack

- **Language:** Kotlin
- **UI:** XML Views
- **Minimum Android version:** Android 7.0 (API 24)
- **Build system:** Gradle

## Status

🚧 **In development**

The project is being developed incrementally. The basic game structure, main menu, settings system, language selection and about screen are already being built.

More customization options and gameplay features will be added over time.
